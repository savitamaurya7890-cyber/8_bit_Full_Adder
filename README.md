 8-Bit Full Adder Using Verilog HDL

Project Overview
Design, Simulation, and Hardware Implementation of an 8-Bit Full Adder using Verilog HDL and Xilinx Vivado on FPGA Board | RTL Design | FPGA

Tools Used
- Verilog HDL
- Xilinx Vivado
- FPGA Design
- RTL Simulation

 Design Description
The 8-bit Full Adder performs binary addition of two 8-bit inputs along with a carry-in.

Inputs
- A [7:0] – First 8-bit input
- B [7:0] – Second 8-bit input
- Cin – Carry input

 Outputs
- Sum [7:0] – 8-bit sum output
- Cout – Carry output

Key Learning
- RTL coding using Verilog
- Combinational circuit design
- Testbench development
- Functional simulation using Vivado
